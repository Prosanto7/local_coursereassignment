# Course Re-assignment Plugin

## Overview
This plugin provides functionality to re-assign courses and quizzes to participants who have exhausted their attempt limits or failed. It maintains historical records before re-assignment and sends email notifications.

## Features
- Course re-assignment for enrolled users
- Quiz re-assignment for specific quizzes
- Historical data tracking before re-assignment
- Email notifications with customizable templates
- User and course/quiz validation
- Searchable dropdown/autocomplete fields

## Installation
1. Copy the plugin folder to `/local/coursereassignment`
2. Visit Site administration > Notifications to install the plugin
3. Configure email templates in Site administration > Courses > Course Re-assignment Settings

## Usage
- **Course Re-assignment**: Site administration > Courses > Re-Assign Course
- **Quiz Re-assignment**: Site administration > Courses > Re-Assign Quiz
- **History**: View historical re-assignment records

## Requirements
- Moodle 4.1 or later
